EMPLACEMENT DE L’AVATAR

Ajoute ici ton avatar final sous le nom exact : avatar.png
Chemin attendu par le site : assets/avatar/avatar.png

Format conseillé : PNG avec fond transparent, personnage entier visible, image verticale.
Taille conseillée : environ 512 × 1024 px (ou un ratio proche de 1:2).
Le site conserve automatiquement le repère « KF » tant que le fichier n’est pas présent.
